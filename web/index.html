The useful hard cases

  • A repeated submission creates one enquiry.
  • A double approval does not create two outgoing messages.
  • A failed job keeps the exact approved reply for recovery.
  • An incoming reply suppresses pending follow-ups.
  • Conflicting prices are escalated instead of guessed.
  • Changed owner facts take effect without restarting.

THE DELIVERY PATH

Customer chat→Saved enquiry→n8n→Staff approval→Persistent outbox→Preview / SMTP

Default: no paid API requests, no external email and no publication. SMTP is opt-in, allowlisted and stops for a manual check if delivery becomes uncertain.
